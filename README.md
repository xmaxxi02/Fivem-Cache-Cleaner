# 🧹 FiveM One-Click Cache Cleaner & Launcher

A lightweight, beginner-friendly tool that safely clears the FiveM cache with just a double-click and automatically launches the game afterward. 

This tool was specifically designed to help players without much technical experience. It eliminates the hassle of manually navigating through hidden Windows folders and prevents the accidental deletion of wrong files.

## 🎯 For Server Owners & Support Teams
Perfect for your Discord server! Simply link this tool in your `#faq` or `#support` channel. 
When players report texture bugs, connection issues, invisible objects, or "endless loading screens," just point them to this tool. It drastically reduces your support tickets and gets players back into RP in seconds.

## ✨ Features
* **1-Click Solution:** No installation required. Just run the `.exe`.
* **100% Safe:** It **only** deletes the error-prone folders (`cache`, `server-cache`, and `server-cache-priv`). 
* **No Huge Downloads:** The `game-storage` folder (which contains the massive game files) remains completely untouched! Players will *not* have to re-download FiveM.
* **Auto-Start:** Once the cache is clean, FiveM launches automatically.
* **No Admin Rights Needed:** Runs seamlessly with standard Windows user permissions.

## 🚀 How to Use (For Players)

1. Download the latest version from **[Releases]** (on the right side of this page).
2. Close FiveM if it is currently running in the background.
3. Run the downloaded file (e.g., `FiveM_Cache_Cleaner.exe`).
4. A small black window will open for a brief moment, clean the cache, and automatically restart FiveM.
5. Have fun playing!
